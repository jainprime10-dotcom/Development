# Sprint 01 — Foundation and Design

## Goal
Create a reliable repository and approved design foundation for the public marketing website.

## In scope
1. Create private GitHub repository.
2. Scaffold Next.js 16 with TypeScript, App Router, Tailwind and ESLint.
3. Add shadcn/ui and establish warm-luxury design tokens.
4. Configure Supabase project and environment-variable conventions.
5. Configure Prisma 7 and PostgreSQL connection adapter.
6. Add shared AI agent instructions.
7. Create Figma design file and approved responsive homepage frames.
8. Implement the approved homepage and core marketing page skeleton.
9. Add lint, typecheck, build and browser-test workflow.

## Out of scope
- Customer login
- Admin CRM
- Payment processing
- Booking engine
- Guest list management
- Vendor marketplace

## Acceptance criteria
- Repository is private and has a protected `main` branch.
- `.env` and `.env.local` are ignored by Git.
- Local development server starts successfully.
- Lint, typecheck and production build pass.
- Figma contains desktop and mobile homepage frames and design tokens.
- Implemented UI follows approved Figma frames.
- No fake testimonials, client logos, awards or portfolio claims.
- No production secrets are committed.

## Definition of done
A reviewer can clone the repository, follow README setup instructions, run the app locally, inspect the approved design references and understand the next implementation task.
